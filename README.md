교차는 계좌의 모든 포지션이 증거금을 공유한다. 한 포지션의 이익이 다른 포지션의 손실을 메워서 계좌 전체로 보면 버티는 힘이 생긴다. 대신 한 곳에서 크게 밀리면 다른 포지션과 잔고까지 함께 끌려간다. 격리는 포지션마다 증거금과 손익을 따로 계산해서, 그 포지션에 넣은 금액이 소진되면 거기서 끝난다.

교차 모드의 미실현 이익은 추가 진입에 쓸 수 있다. 다만 그 이익을 다른 곳으로 옮기거나 다른 거래에 쓰지는 못한다. 이익이 난 상태에서 포지션을 더 열면 평균 진입가가 바뀌고, 예상 청산가가 평균 진입가 쪽으로 가까워진다. 수익이 커 보이는 순간에 위험도 같이 커지는 구조다.

### 2. KYC와 2단계 보안

OKX는 신원 인증을 요구한다. 앱에서 Get Verified → 지금 인증하기로 들어가 신분증 종류를 고르고 앞면과 뒷면을 촬영한 다음 실시간 얼굴 인증을 한다. 신분증에서 읽어낸 인적 사항을 확인하고 도로명 주소와 우편번호를 넣으면 끝난다. 보통 10~30분 안에 승인된다.

인증 등급은 두 단계다. Level 1은 이메일과 전화번호 같은 기본 정보만 넣는 단계로 입금과 거래가 제한적으로 열린다. Level 2에서 신분증과 셀카를 올리면 한도가 올라가고 거래 기능과 출금이 온전히 열린다. 선물거래를 제대로 하려면 Level 2까지 마치는 쪽이 낫다.

2단계 보안은 구글 OTP로 걸어둔다. 프로필 아이콘 → Security → Setup에서 휴대폰과 이메일 인증을 한 번 더 하고, 화면에 뜬 QR코드를 구글 OTP 앱으로 스캔해 나온 6자리 숫자를 OKX에 입력하면 설정이 끝난다.

## 유지증거금률 300%와 100%, 청산은 이렇게 온다

포지션 영역에서 유지증거금률을 볼 수 있다. 이 숫자가 300% 이하로 내려가면 시스템이 포지션 축소 경고를 보내고, 100% 이하가 되면 규칙에 따라 주문을 취소한 뒤 강제청산을 실행한다. 단일 통화 증거금 모드든 교차 통화 증거금 모드든 기준은 같다. 300%는 아직 여유가 있지만 손실이 빠르게 불어나고 있다는 신호이고, 100%는 그 시점에 포지션이 정리된다는 뜻이다.
